# Fiestapp

**Cuentas claras, relaciones largas.**

Fiestapp es una app para iPhone hecha en SwiftUI para organizar salidas con amigos
(fiestas, comidas, viajes) y dividir los gastos sin broncas:
registras quién pagó qué,entre quiénes se divide y la app te dice quién le debe a quién.
